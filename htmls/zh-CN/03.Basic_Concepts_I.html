C++ 类型系统

3/29

C++ 是强类型、静态类型语言

  • 每个实体都有类型，并且类型本身不会在运行时改变。
  • 变量、函数和表达式都必须具有类型，程序才能被编译。
  • 用户可以通过类、结构体、枚举和别名等机制定义自己的类型。
  • 类型系统既是安全机制，也是表达程序设计意图的工具。
4/29

类型分类

  • 基本类型：语言自身提供，不需要额外头文件，常被称为 primitive types。
  • 复合类型：由其他类型组合而成，包括数组、指针、引用、函数、枚举、类和结构体等。
  • 理解基本类型是理解对象模型、内存布局、转换规则和运算符行为的前提。
5/29 - 6/29

类型属性

  • 对象类型：具有大小，能对其使用 sizeof。
  • 标量类型：保存单个值，不由其他对象组合而成。
  • 平凡可复制：可以按位复制。
  • 标准布局：对象布局满足标准规定，适合与 C 互操作或进行底层布局推理。
  • 这些属性常用于模板约束、性能优化和 ABI 相关判断。
7/29

C++ 类型总结

  • C++ 类型体系庞大，但可以先按“基本类型”和“复合类型”建立主干。
  • 后续课程会继续展开类、枚举、引用、指针、函数、模板和标准库类型。
  • 类型不是语法附属品，而是 C++ 表达抽象、约束和性能特征的核心。

基本类型概览

8/29

算术类型：整数

  • 原生整数类型包括 bool、char、short、int、long、long long 及其有符号/无符号变体。
  • 字节数和范围与实现相关，不应在可移植代码中盲目假设。
  • <cstdint> 提供固定位宽类型，例如 std::int32_t、std::uint64_t。
9/29

算术类型：浮点

  • 常见浮点类型包括 float、double 和 long double。
  • 多数平台使用 IEEE-754 表示，但 long double 的大小和格式更依赖实现。
  • C++23 引入 <stdfloat>，用于描述更多固定宽度浮点类型。
10/29

算术类型简写

完整写法 常用简写
signed short int short
signed int int
signed long int long
unsigned int unsigned
11/29 - 12/29

字面量后缀与前缀

  • 整数后缀可指定类型，例如 3u 表示 unsigned int，5LL 表示 long long。
  • 浮点后缀可指定精度，例如 1.0f 是 float，1.0L 是 long double。
  • 前缀用于表示进制：0b 二进制、0 八进制、0x 十六进制。
auto a = 42;       // int
auto b = 42u;      // unsigned int
auto c = 0b1010;   // binary literal
auto d = 0xff;     // hexadecimal literal
13/29

其他算术类型

  • C++ 也提供 long double，但它不一定对应 IEEE-754 固定格式。
  • C++23 前，低精度浮点支持通常依赖编译器扩展或平台特性。
  • 实际工程中应确认目标平台、ABI 和编译器对数值类型的具体支持。
14/29

void 类型

  • void 是不完整类型，没有值。
  • void 可表示函数没有返回值，或在 C 风格函数声明中表示无参数。
  • void* 是指向未知类型对象的指针，但在 C++ 中使用时需要更谨慎。
15/29

nullptr 关键字

  • C++11 引入 nullptr 表示空指针，用来替代 NULL 宏。
  • nullptr 的类型是 std::nullptr_t，比整数常量 0 更安全。
  • 在重载解析中，nullptr 能减少 0 或 NULL 带来的歧义。
void f(int);
void f(int*);

f(nullptr); // 调用 f(int*)

转换规则

16/29

隐式类型转换

  • 在执行运算前，C++ 会按规则对操作数进行隐式类型转换。
  • 常见步骤包括浮点提升、整数提升、算术转换等。
  • 这些规则会影响表达式的最终类型和值，尤其是有符号/无符号混合运算。
17/29

示例与常见错误

float    f = 1.0f;
unsigned u = 2;
int      i = 3;

auto x = u - i; // 需要理解 unsigned 与 int 的转换规则
  • 混合类型运算可能把有符号值转换为无符号值。
  • 转换结果不一定符合直觉，比较和减法尤其容易出错。
18/29

隐式提升

  • 小于 32 位的整数类型通常会被提升为 int，无论原始类型是否有符号。
  • 一元 +、-、~ 和二元算术/位运算都会触发相关提升。
  • 写底层代码时，要特别注意 char、short、位运算和符号扩展。

auto 关键字

19/29

auto 变量 1/3

  • C++11 中，auto 表示变量类型由编译器根据初始化器自动推导。
  • 推导的是表达式结果类型，而不是开发者“想象中的类型”。
  • auto 可以减少冗长类型名，但不能替代理解类型。
auto a = 1 + 2;     // int
auto b = 1.0 + 2;   // double
auto c = 3u;        // unsigned int
20/29

auto 函数返回类型 2/3

  • C++11/C++14 中，auto 和 decltype 可用于函数返回类型。
  • C++11 支持尾置返回类型；C++14 起可让编译器推导返回类型。
auto g(int x) -> int { return x * 2; } // C++11
auto h(int x) { return x * 2; }        // C++14
21/29

auto 函数参数 3/3

  • C++20 中，auto 也可用于函数输入参数。
  • 这种写法本质上等价于简化的函数模板。
void f(auto x) {}

template <class T>
void f(T x) {}

C++ 运算符

22/29

运算符概览

  • C++ 运算符有优先级和结合性。
  • 后缀自增/自减、前缀自增/自减、一元运算、乘除取模、加减、移位、比较、逻辑和赋值等都有固定优先级。
  • 不要依赖读者记忆复杂优先级；必要时使用括号表达意图。
23/29 - 24/29

运算符优先级

  • 一元运算符优先级高于二元运算符。
  • 标准数学运算符中，乘除取模优先于加减。
  • 比较、逻辑与、逻辑或、赋值的优先级依次降低。
a + b * 4;       // a + (b * 4)
a * b / c % d;   // ((a * b) / c) % d
25/29

前缀/后缀自增语义

  • 前缀：++i 先更新值，再返回更新后的值。
  • 后缀：i++ 先保存旧值，再更新对象，表达式结果是旧值。
  • 对迭代器等类型，前缀形式通常更直接，也可能更高效。
26/29

运算顺序和未定义行为

  • 某些表达式在不同 C++ 标准中有不同的求值顺序规则。
  • 在一个表达式中多次修改同一对象，或同时读写而顺序未定义，会导致难以推理的行为。
  • 工程实践中应写成多条清晰语句，不把副作用藏进复杂表达式。
int i = 0;
i = ++i + 2; // 旧标准中有未定义行为风险；仍不建议这样写
27/29

赋值、复合赋值和逗号运算符

  • 赋值和复合赋值运算符是从右到左结合。
  • 赋值表达式会返回被赋值后的对象。
  • 逗号运算符从左到右求值，整个表达式结果是最后一个子表达式。
int x;
int y = 2;
x = y = 4; // y 先被赋值，随后 x 被赋值
28/29

三路比较运算符 <=>

  • C++20 引入三路比较运算符 <=>，也称 spaceship operator。
  • 它可以像 strcmp 一样一次性表达“小于、等于、大于”的比较结果。
  • 返回对象可与 0 比较，也可帮助编译器生成常规比较运算。
29/29

安全比较函数

  • C++20 在 <utility> 中提供安全比较函数，用于比较不同整数类型。
  • 这些函数能减少有符号/无符号混合比较带来的陷阱。
std::cmp_equal(a, b);
std::cmp_less(a, b);
std::cmp_greater(a, b);
